# Pi Rakit

Installer interaktif untuk memilih dan memasang kumpulan ekstensi Pi.

```bash
npx pi-rakit
npx pi-rakit --list-packages
npx pi-rakit --list-packages --json
npx pi-rakit --local --package ponytail --package caveman --yes
```

Gunakan `--package <id>` berulang kali untuk memilih package tertentu tanpa prompt interaktif. Tambahkan `--json` ke `--list-packages` untuk output yang dapat diproses program. Jalankan `npx pi-rakit --help` untuk melihat semua opsi.
